# Proof: anti-Ramsey lower bounds for pG with non-bipartite G, and the failure of (★)

Status labels. Lemmas A–C re-prove, self-contained, the constructions of Gorgol–
Görlich [GG17] (Thm 3.1, Thm 3.6). Proposition D and Theorem E are the new part —
modulo the fact that the construction is the natural generalisation of [GG17,
Thm 3.6] (folklore-level; literature search found no statement at this generality,
see research/literature_review.md).

Notation: G connected, |V(G)| = n ≥ 3, χ(G) = r. T_q(m) = complete q-partite graph on
m vertices, part sizes balanced; e(T_q(m)) = ⌊(q−1)m²/(2q)⌋.

## Lemma A (construction). Fix q ≥ 1. Color K_m: every edge whose endpoints lie in
different parts of T_q(m) gets a **distinct** color; every edge inside a part gets
the single extra color γ (distinct from all cross colors). Uses e(T_q(m)) + 1 colors,
and every coloring of K_m in which all edges of T_q(m) are pairwise distinctly
colored but two edges inside parts share one color γ has: any subgraph containing ≥ 2
inside-edges is NOT rainbow.

*Proof.* Trivial color-counting. ∎

## Lemma B (copies of non-q-partite graphs must use an inside edge).
If χ(G) = r > q, then under the coloring of Lemma A every copy of G in K_m contains
at least one edge colored γ.

*Proof.* If a copy Ĝ of G used only cross edges, Ĝ would be a subgraph of the
q-partite graph T_q(m), hence q-colorable; but χ(Ĝ) = χ(G) = r > q. ∎

## Proposition C (general Thm-3.6 analogue; PROVED HERE, folklore-level novelty)
For connected non-bipartite G (r ≥ 3), q = r − 1 ≥ 2, any p ≥ 2, any m ≥ 1:

> **ar(m, pG) ≥ e(T_q(m)) + 1.**

*Proof.* Lemma A coloring. Let H be any copy of pG in K_m: H is the vertex-disjoint
union of copies G₁, …, G_p of G. By Lemma B each Gᵢ contains ≥ 1 γ-edge. The Gᵢ are
vertex-disjoint, hence edge-disjoint, so H contains ≥ 2 distinct γ-edges (p ≥ 2
copies). By Lemma A, H is not rainbow. So the coloring avoids rainbow pG and uses
e(T_q(m)) + 1 colors. ∎ (audited: the only subtle point — edge-disjointness of the
γ-edges from vertex-disjointness — checked verbatim.)

Instance check: G = K₃ (r = 3, q = 2), p = 2: ar(m, 2K₃) ≥ ⌊m²/4⌋ + 1 — exactly
[GG17, Thm 3.6]. For K₄-family (r = 4, q = 3): ar(m, 2K₄) ≥ e(T₃(m)) + 1 = ⌊m²/3⌋ + 1,
m ≥ 8. For C_{2k+1} (r = 3, q = 2): ar(m, 2C_{2k+1}) ≥ ⌊m²/4⌋ + 1, m ≥ 4k+2.

## Theorem D (separation for odd cycles; PROVED HERE, modulo [MNL05])
Write C_{2j+1} for the odd cycle with 2j+1 vertices, j ≥ 1. Define

> RHS(m) := ar(m−1, C_{2j+1}) + m − 1 = the value of formula (★) at (p, G) = (2, C_{2j+1}).

Then **ar(m, 2C_{2j+1}) ≥ ⌊m²/4⌋ + 1 > RHS(m) for every m ≥ 8j + 2** (and, by exact
computation, already for all m ≥ sep(j), where sep(1) = 6, sep(2) = 10, sep(3) = 14,
sep(4) = 18 — see results/odd_cycles_separation.csv; the interval
[sep(j), 8j+1] is covered numerically). Consequently Conjecture 3.2 in its eventual
reading fails for every odd cycle at all m ≥ 8j + 2, with the gap growing like m²/4:
no constant m₀ can rescue the conjecture for odd cycles.

*Proof.* Proposition C gives ar(m, 2C_{2j+1}) ≥ e(T₂(m)) + 1 = ⌊m²/4⌋ + 1 (r = 3, q = 2).

For the RHS we use the exact cycle formula (Montellano-Ballesteros & Neumann-Lara
[MNL05, Thm 5], fixing the ⌈·⌉/−1 obscured in [GG17, Thm 2.3]'s PDF extraction —
verified against [MNL05]'s h(n,p) = E(n,p) and against Alon's exact ⌊4n/3⌋ − 1 for
C₄): for n ≥ 2j+1, with r := n mod 2j:

  ar(n, C_{2j+1}) = j(2j−1)·⌊n/(2j)⌋ + C(r, 2) + ⌈n/(2j)⌉ − 1
                  = ((2j−1)/2 + 1/(2j))·n + ε_j(n),

where the "error" is ε_j(n) = C(r,2) + [r ≥ 1] − 1 − ρ_j·r with ρ_j :=
(2j−1)/2 + 1/(2j) =: s_j < j (for j ≥ 1: s_j = (2j−1)/2 + 1/(2j) ≤ ½ + 1/(2j) + (2j−2)/2·...:
indeed s_j ≤ j − ½ + 1/(2j) < j). Bounds: 0 ≤ C(r,2) + [r≥1] ≤ C(2j−1,2) + 1 < 2j²,
and 0 ≤ ρ_j·r ≤ s_j(2j−1) < j·2j = 2j², so **−2j² ≤ ε_j(n) ≤ 2j²**. Hence for m ≥ 2j+2:

  RHS(m) ≤ s_j·(m−1) + 2j² + m − 1 ≤ (s_j + 1)·m + 2j² ≤ (j+1)·m + 2j²,

using s_j + 1 ≤ j + 1. Therefore, for m ≥ 8j + 2:

  ⌊m²/4⌋ + 1 − RHS(m) ≥ m²/4 − (j+1)m − 2j² − 1
                      ≥ (at m = 8j+2) 16j² + 8j + 1 − 8j² − 10j − 2 − 2j² − 1
                      = 6j² − 2j − 2 ≥ 0   (j ≥ 1, with equality margin +2 at j=1),

and the quadratic m²/4 − (j+1)m − 2j² − 1 is strictly increasing for m ≥ 2j+2 <
8j+2 (derivative m/2 − j − 1 > 0), so the inequality ⌊m²/4⌋ + 1 > RHS(m) holds for
ALL m ≥ 8j + 2. For j = 1 (K₃) this is even an exact statement (no error term:
ar(n, K₃) = n − 1), giving separation from m = 6 on; see Corollary E. The numeric
table (results/odd_cycles_separation.csv, generated by
experiments/odd_cycles_separation.py) refines the start of separation to sep(j) and
confirms LB − RHS is strictly increasing beyond sep(j) for j ≤ 4 up to m = 90. ∎

(Hostile-audit status of Theorem D: the sole inputs are Proposition C — audited
above — and [MNL05, Thm 5], ESTABLISHED IN PRIOR WORK, plus the bounded-error
estimate ε_j, whose two-sided bound |ε_j| ≤ 2j² is routine; the numeric table is
script-generated and re-runnable. The symbolic tail m ≥ 8j+2 does not depend on the
table.)

## Corollary E (instance K₃; ESTABLISHED IN PRIOR WORK as to the bounds used)
For every m ≥ 6: ar(m, 2K₃) ≥ ⌊m²/4⌋ + 1 > 2m − 3 = ar(m−1, K₃) + m − 1
(ar(m,K₃) = m−1 [ESS 1973], exact, no residues). So for G = K₃, p = 2, (★) fails at
EVERY m ≥ 6 with unbounded gap — a strong quantitative form of the paper's own
"unlikely sharp" remark. ∎

## Where this leaves the research question

The non-tree branch of Conjecture 3.2 is settled in the negative direction (for
non-bipartite G the conjectured equality fails at every sufficiently large m with
quadratic gap; the paper itself never claimed equality for non-trees — it claimed
"iff tree" — so our contribution is the explicit, quantified, all-scale failure and
the generalised construction). The tree branch remains the genuinely open part:
F1/F2 (stars) are where a real theorem attempt is live. See mathematics/attack_2stars.md.
