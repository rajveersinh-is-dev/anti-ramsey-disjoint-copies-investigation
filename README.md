Autonomous investigation of Gorgol-Gorlich Conjecture 3.2 (anti-Ramsey numbers for disjoint copies): proofs, exact CP-SAT experiments, hostile audits. Falsified small-m regime; eventual-exactness threshold improved 69 -> 29 (pending audit).

## Overview

`anti-ramsey-disjoint-copies-investigation` provides algorithmic implementations and mathematical models for scientific and cryptographic applications, focusing on numerical stability, invariant verification, and performance.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/anti-ramsey-disjoint-copies-investigation.git
cd anti-ramsey-disjoint-copies-investigation
pip install -r requirements.txt
```

Run the automated verification suite:

```bash
pytest tests/
```
